# Changelog

All notable changes to ContextPilot are documented here.

## 0.1.0 - 2026-07-28

### Added

- Local-first repository indexing and content-addressed SQLite summary cache
- Task-aware file and symbol retrieval with explainable ranking
- Hierarchical `AGENTS.md` discovery
- Git diff context generation
- Budgeted Markdown prompt compilation and estimated token reports
- Per-task baseline-versus-optimized estimates and cumulative usage history
- Global `context-pilot` CLI
- Codex MCP server with context preparation, indexing, diff, and statistics tools
- `context-pilot codex install` for automatic Codex app configuration
- Automated tests and npm release validation
